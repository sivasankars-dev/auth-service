# ⚙️ Tech Stack

## 🚀 Backend

**FastAPI**
- Async-first framework built on ASGI
- High throughput with non-blocking I/O
- Dependency Injection for modular and testable services

---

## 🗄️ Database

**PostgreSQL**
- Strong consistency guarantees
- Optimized indexing for lookup-heavy workloads
- Full ACID compliance for transactional integrity

---

## 🔐 Security

- **Argon2**
  - Industry-standard password hashing
  - Resistant to GPU & brute-force attacks

- **JWT (HS256 / RS256)**
  - Stateless authentication
  - Supports key rotation (RS256)

- **Pydantic**
  - Strict input validation
  - Prevents malformed request payloads

---

## 🧬 Migrations

**Alembic**
- Version-controlled schema evolution
- Safe, incremental database changes

---

## 🧪 Testing

**pytest**
- Unit tests for business logic
- Integration tests for API & DB flows
